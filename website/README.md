# SYNVOX website

Статический продуктовый сайт и официальный хаб обновлений SYNVOX на SvelteKit.

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test
npm run check
npm run build
npm run test:e2e
```

Production-сборка создаётся в `build/`.

## Предпросмотр загрузки и установки

Инструкции: `/instructions/` и `/en/instructions/`. Для локальной проверки перед сборкой сайта:

```bash
cd ..
node scripts/build-desktop-preview.mjs
mkdir -p website/static/downloads
cp output/desktop-preview/synvox-desktop-preview.zip* website/static/downloads/
cd website
npm run build
npm run preview -- --host 127.0.0.1 --port 4193
```

Архив предназначен для проверки владельцем. Генератор не публикует обновления и не изменяет
подписанный desktop/update.json. Повторную сборку делайте в новом выходном каталоге (аргумент
скрипта). ZIP и контрольная сумма исключены из Git. Без них сборка сайта намеренно падает на
проверке ссылок. Публичный релиз — только после проверки и отдельного одобрения.

## Обновление контента

Позиционирование, возможности, платформы и состояние первого релиза находятся в
`src/lib/content/site.js`. Сайт указывает только на подготовленные versioned-архивы: не меняйте
ссылки на несуществующие файлы. SYNVOX 0.5.65 распространяется бесплатно для личного
использования; активация и подписка не требуются.

## Правовой архив

Публичные реквизиты и архив условий прежних оплат находятся в
`src/lib/content/commercial.js`; страница `/documents/` явно сообщает, что это не
предложение купить SYNVOX. Не добавляйте на сайт оплату, тарифы, пожертвования или
обещания возврата без отдельного решения владельца и правовой проверки.
