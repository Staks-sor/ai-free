## Текст страницы

### Помощник рядом с кодом

Чтобы обсудить функцию с нейросетью, можно вставить её в веб-чат. Для задачи в нескольких файлах нужен ещё контекст проекта: где находится реализация, что можно менять и как проверить результат.

SYNVOX связывает AI-провайдера с выбранной рабочей папкой. Начните с обзора кода без изменений, затем поручите небольшую правку. Чтение файлов, редактирование и запуск команд зависят от выбранного режима и разрешений.

### Начало работы в VS Code

1. Откройте папку проекта через «Файл → Открыть папку». Для первой проверки выберите небольшой проект без секретов.
2. Установите VS Code-плагин SYNVOX. Если у вас файл `.vsix`, откройте Extensions, меню с многоточием и выберите Install from VSIX. После установки выполните перезагрузку окна, если редактор предложит её.
3. Откройте SYNVOX в боковой панели. Подключите нужного провайдера через настройки аккаунтов и проверьте статус подключения.
4. Создайте чат и проверьте рабочую папку. Название открытого проекта само по себе не заменяет проверку пути в SYNVOX.
5. Отправьте первую задачу из примера ниже. Сверьте названные файлы с проектом перед разрешением правок.

### Начало работы в PyCharm

1. Откройте проект в PyCharm. Сверьте совместимость версии IDE с требованиями устанавливаемого пакета.
2. Если у вас ZIP плагина, откройте Settings → Plugins, меню с шестерёнкой и выберите Install Plugin from Disk. Перезапустите IDE, если она попросит.
3. Откройте окно SYNVOX, подключите AI-провайдера и проверьте рабочую папку чата.
4. Начните с обзора структуры. Для запуска тестов используйте команду, подходящую окружению именно этого проекта.

Плагины и десктоп обновляются отдельно. Десктопный архив нельзя устанавливать как VSIX или ZIP плагина JetBrains. Требования к Node.js и окружению смотрите для выбранного пакета; они могут отличаться от десктопной инструкции.

### Первая задача без изменения файлов

> Изучи выбранный проект. Пока не меняй файлы и не запускай команды. Покажи точку входа, три основных модуля и их назначение. Подтверди выводы путями файлов. Если папка недоступна, сообщи точную проблему, не придумывай структуру.

Убедитесь, что перечисленные файлы действительно существуют и объяснение относится к вашему коду. Если AI не видит проект, сначала проверьте выбранный путь, режим и разрешения.

### От обзора к небольшой правке

Выберите одну воспроизводимую ошибку. Опишите ожидаемое поведение, ограничения и проверку результата. Например:

> Найди причину двойной отправки формы. Сначала покажи обработчик и предложи тест. После согласования внеси минимальную правку. Не меняй дизайн и зависимости. Запусти разрешённые проверки и перечисли изменённые файлы.

После выполнения просмотрите изменения и повторите исходный сценарий. Если тест не запущен, результат остаётся непроверенным. Не разрешайте удаление данных, публикацию или изменение рабочей базы как неявную часть задачи.

### Аккаунт AI и подписка SYNVOX

SYNVOX — клиент для работы с проектом, а не собственная языковая модель. Подключайте свои аккаунты доступных провайдеров. Оплата SYNVOX не включает сторонние подписки и не снимает ограничения моделей или сервисов.

Если провайдер требует вход или ручную проверку, завершите её в показанном окне. Наличие платной подписки не гарантирует отсутствие ограничений. Пароли, cookies и токены не нужно вставлять в чат.

### Где находятся данные

История и память проекта хранятся локально. Запрос и необходимый контекст передаются выбранному AI-провайдеру. Перед работой с закрытым кодом проверьте правила организации и условия этого сервиса.

## Блок для главной

### Ваш AI-аккаунт и выбранный проект

Подключите свой аккаунт доступного AI-провайдера, выберите рабочую папку и начните с небольшой задачи. SYNVOX помогает связать диалог с файлами проекта и разрешёнными действиями.

Подписка SYNVOX оплачивает клиент. Аккаунты, тарифы и ограничения сторонних сервисов остаются отдельными. История хранится локально, но необходимый контекст отправляется выбранному провайдеру.

Кнопка: «Скачать SYNVOX». Дополнительная ссылка: «Как подключить аккаунт» — на соответствующий раздел инструкции после его подготовки.

## Условия публикации

- Добавить прямые проверенные ссылки на доступные пакеты VS Code и JetBrains. Не подменять их ссылкой на десктоп.
- Повторить оба маршрута на пакетах, которые будут доступны посетителю; сверить названия кнопок и требования среды.
- Добавить настоящие скриншоты установки, выбранной папки и результата первой задачи. Не показывать аккаунты, ключи и приватный код.
- Предоставить владельцу предпросмотр текста и ссылок. После утверждения синхронизировать английский материал.

Редакционная проверка: сохранены ограничения провайдеров и передачи контекста, убраны устаревшие заявления о подготовке выпуска. Пример задачи не представлен как уже выполненный кейс. Нет обещаний экономии времени, гарантированного результата или обхода CAPTCHA.

Основания для инструкции: `plugin-for-vscode/package.json`, `plugin-for-vscode/extension.js`, `plugin-for-jetbrains/src/main/resources/META-INF/plugin.xml` и README плагинов. README содержит устаревшие сведения; точные требования пакетов нужно подтвердить перед публикацией.
