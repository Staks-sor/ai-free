## Что изменилось

Первое подключение Qwen/DeepSeek показывает этапы проверки Python, подготовки окружения, установки Camoufox и загрузки браузера. Требуется Python 3.10+ из PATH; на Windows при установке нужно включить добавление в PATH и полностью перезапустить IDE. При отсутствии подходящего Python настройки предлагают официальный сайт. Python глобально автоматически не устанавливается.

Ошибки установки, загрузки, прав записи, запуска и отсутствующего графического экрана имеют отдельные коды и безопасные инструкции. Linux/WSL/SSH без DISPLAY/WAYLAND_DISPLAY сразу объясняет необходимость графической среды. Сбой подготовки сохраняет действующий вход; повторная попытка использует уже созданное окружение. Старое или повреждённое Python-окружение переносится в venv-backup-* и создаётся заново подходящим Python; профили аккаунтов не переносятся и не удаляются. Отдельные провайдеры могут авторизоваться параллельно; один аккаунт по-прежнему защищён от конкурирующего открытия.

Qwen сохраняет ограниченную проверку готовности страницы, CDN-скриптов и служебного модуля. После двух ожиданий и одной перезагрузки выдаётся понятная транспортная ошибка с признаком «запрос не отправлен». Она не объявляет сессию истёкшей. Поддержан main-скрипт с хешем имени. Guards модели/ветки/доставки сохранены. Обход CAPTCHA не добавлялся.

UI различает подготовку, ожидание входа и сохранённые данные. Статус «Вход сохранён» не обещает доступность сети. Длительная подготовка не превращается в ложное сообщение об отсутствующем токене. В VS Code добавлен portMapping локального backend для remote workspace. Уже исправленные CSP, экран загрузки и ошибки запуска включены.
