# От загрузки до первого чата

SYNVOX 0.5.65: один ZIP для macOS, Windows и Linux. Альфа-версия, не готовый установщик. Требуется Node.js 22+.

https://synvox.pro/instructions/

## 1. Установите Node.js

Установите Node.js 22 с официального сайта, выбрав свою систему и процессор. npm входит в комплект. Откройте новое окно терминала и проверьте версии. Нужны интернет и собственный аккаунт AI-провайдера.

```
node --version
npm --version
```

Для входа Qwen/DeepSeek также нужен Python 3.10+ с https://www.python.org/downloads/. На Windows включите добавление Python в PATH при установке и откройте новое окно терминала. При первом подключении SYNVOX скачает Camoufox и браузер; этапы подготовки видны в «Настройки → Аккаунты». Нужен доступ к PyPI и загрузкам GitHub.

## 2. Распакуйте архив

Windows: правой кнопкой по ZIP → «Извлечь всё». macOS: двойной щелчок по ZIP. Linux: «Распаковать» в файловом менеджере. Используйте отдельную папку SYNVOX, не запускайте внутри ZIP и не распаковывайте поверх старой версии.

## 3. Установите зависимости

Откройте папку с package.json. Windows: в адресной строке Проводника введите cmd и нажмите Enter. macOS/Linux: в Терминале введите cd с пробелом, перетащите распакованную папку в окно и нажмите Enter. Выполните команду и дождитесь загрузки зависимостей и браузеров — это может занять несколько минут.

```
npm ci
```

## 4. Запустите программу

Выполните команду в той же папке. Оставьте терминал открытым. Для последующих запусков нужна только эта команда; для остановки нажмите Ctrl+C в терминале.

```
npm start
```

## 5. Подключите AI и проект

Выберите провайдера, войдите в свой аккаунт через предложенное окно авторизации. Создайте чат, выберите модель и папку проекта. Сначала попросите описать проект без изменения файлов. Проверьте разрешения в настройках перед правками и командами. Используйте копию проекта или отдельную Git-ветку. Аккаунты и лимиты сторонних AI в SYNVOX не входят.

## 6. Доступ

SYNVOX доступен бесплатно для личного использования. Условия и лимиты AI-провайдеров действуют отдельно.

https://nodejs.org/en/download

## Обновление с предыдущей версии

Остановите старую программу через Ctrl+C в её терминале. Распакуйте новый архив в отдельную папку, например C:\SYNVOX-0.5.65, откройте вложенную папку SYNVOX с package.json, затем выполните npm ci и npm start. В начале вывода должна появиться версия 0.5.65. Старую папку сохраните; пользовательские каталоги .deepseek-cli, .qwen-cli и .ai-free не удаляйте. Чаты, настройки и входы в AI хранятся отдельно от папки программы.

## node или npm не найдены

Установите Node.js 22, закройте и заново откройте терминал. Повторите проверку версии.

## Ошибка package.json / ENOENT

Перейдите в распакованную папку с package.json и повторите команду.

## Не скачался браузер / нет библиотек Linux

Проверьте интернет и повторите npm ci. Linux может потребовать системные библиотеки браузера. Отправьте точную ошибку в поддержку; не отключайте защиту системы.

## Управление компьютером

Для экрана, мыши и клавиатуры выберите «Компьютер» в текущем чате. Windows требует активного рабочего стола; shell — cmd.exe. macOS требует Screen Recording и Accessibility. Linux требует X11 и DISPLAY; Wayland пока не поддерживается. В Ubuntu/Debian могут понадобиться libxtst6, libxrandr2, libxi6; зависимости браузера: npx playwright install-deps chromium. Если @jitsi/robotjs не установлен, повторите npm ci и сохраните ошибку. Чаты, файлы проекта и снимки встроенного браузера работают отдельно от desktop tools. Полный ввод Windows и несколько мониторов ещё требуют ручной проверки.

## Сообщить о проблеме

В версии 0.5.65 нажмите «Сообщить об ошибке» рядом с ошибкой или откройте Настройки → Статус → «Сообщить о проблеме». Введите описание, при желании добавьте контакт и изображение, затем нажмите «Подготовить отчёт». Версия программы и ОС подставятся автоматически. Проверьте данные и сохраните файл кнопкой «Сохранить файл». Онлайн-приём отчётов пока выключен; программа не отправляет их автоматически. Не добавляйте пароли, ключи и чужие данные.
