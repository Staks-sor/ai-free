# SYNVOX 0.5.65

SYNVOX доступен бесплатно для личного использования. Для работы с AI нужны аккаунты провайдеров, а их правила и лимиты действуют отдельно.

- Desktop, VS Code и JetBrains работают без ключа установки, пробного периода и подписки SYNVOX.
- Обновление использует прежние каталоги данных. Чаты, настройки и сохранённые входы в AI остаются доступны.
- Служебные объявления загружаются с сайта и открываются по кнопке с колокольчиком.
- Временное ограничение запросов Qwen больше не исключает аккаунт из доступных. Подтверждённое исчерпание квоты по-прежнему останавливает запросы для этого аккаунта.
- Поддержка по ранее совершённым платежам указана в [документах](https://synvox.pro/documents/#refunds).

Для Desktop скачайте ZIP и следуйте инструкции [на русском](INSTALL-RU.md) или [на английском](INSTALL-EN.md). Для IDE доступны VSIX и JetBrains ZIP. Инструкции по установке плагинов и ссылки доступны на [сайте SYNVOX](https://synvox.pro/instructions/).
