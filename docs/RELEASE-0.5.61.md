# SYNVOX 0.5.61

Подготовлено 2026-11-06. Файлы для ручной публикации владельцем:

- `output/release-0.5.61/synvox-vscode-0.5.61.vsix` — универсальный VS Code-плагин для Windows/macOS/Linux; Visual Studio Marketplace, обновление существующего `developers-daily-life.ai-free-vscode`.
- `output/release-0.5.61/synvox-jetbrains-0.5.61.zip` — JetBrains Marketplace → существующий SYNVOX → Upload Update; ID `ru.stas-sor.ai-free` сохранён.
- `output/release-0.5.61/SHA256SUMS` и `manifest.json` — контрольные суммы и результаты проверки пакетов.

## Изменения

- Устранена подтверждённая причина пустой панели: старый VSIX0.5.60 не разрешал точный внешний origin VS Code в `frame-ancestors`. В0.5.61 включён проверенный CSP-fix без wildcard-разрешений.
- Боковая панель регистрируется до проверки Node.js: показывает загрузку, понятные ошибки запуска и остановки сервера вместо пустого окна.
- Qwen использует постоянный профиль с cookies и кэшем; сохранённая сессия переносится один раз. Загрузка страницы отделена от истёкшего access-токена; тихое обновление и локализованные элементы выбора модели исправлены.
- Компактное сворачиваемое меню и сохранение состояния панели.
- Чаты, аккаунты и ключ установки не сбрасываются при обновлении.
