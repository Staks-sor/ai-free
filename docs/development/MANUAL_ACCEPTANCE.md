## Основные сценарии

1. **Аккаунты:** Настройки → Аккаунты → каждый из пяти AI. Добавить второй, переименовать, сделать основным, перезапустить. Оба сохраняются; новый чат использует основной, старый сохраняет свою identity. Десять разрешены, одиннадцатый отклоняется. Неудачный вход не разрешает отправку.
2. **Общий контекст:** выбрать проект, дать анализ в coding, спросить результат в чате. Роль/skill/сохранённый результат доступны обоим режимам.
3. **Агенты и задачи:** создать профиль с AI/ролью/проектом/skill. Сам не запускается. Запустить задачу: status/цель/проверки/изменённые paths отображаются; завершённый непрочитанный чат подсвечивается.
4. **Продолжение:** безопасно приостановленную задачу продолжить, в том числе быстрым двойным нажатием. Один запрос, черновик/вложения сохранены. Stop отменяет работу/ожидание. После смены аккаунта/проекта или unknown delivery продолжение заблокировано до разбора результата.
5. **Проверки и передача:** отсутствие checks — «не проверен», failed — ошибка; зелёный результат только после успешных checks. Handoff создаёт свежий чат того же проекта с кратким packet и draft, без автоматической отправки.
6. **Нагрузка:** длинная генерация/Stop/reconnect/ограничения; повтор не спамит AI. Проверить Linux startup и повторный запуск. Camoufox используется по назначению, desktop shell/GLM/Web ещё требуют Chromium. Проверить CPU/RSS с двумя задачами, idle cleanup и закрытие процессов после выхода.

Qwen требует входа; CAPTCHA проверяет владелец, универсальный solver не реализован. Память двух активных браузеров ранее около 2 GiB — проверить на целевой машине.
