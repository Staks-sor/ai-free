## Поведение и пути

`src/announcements/client.mjs`: фиксированный HTTPS `synvox.pro/api/v1/announcements.json`,128КБ/5с/no redirects, schema1, до20 сообщений с RU/EN, сроками, уникальным ID и необязательной ссылкой на synvox.pro/t.me. Нет исполнения HTML/команд и передачи ключей/идентификаторов/диагностики. Успешный feed кешируется5мин; ошибка сохраняет память предыдущего ответа, истёкшие сообщения скрываются. Холодный запуск без сети не показывает feed до успешной загрузки.

`src/window-app/routes/announcements.mjs`: защищённые loopback GET `/api/announcements`, POST `/api/announcements/read`; доступны без оплаты. Локальные append/fsync подтверждения в AUTH_DIR/announcements-read.jsonl общие для использующих этот каталог интерфейсов, сохраняются после смены порта/проекта/перезапуска. Ошибка записи не выдаётся за прочтение. Метрик доставки нет.

`src/window-app/announcements-ui.mjs`, `ui-html.mjs`: компактный колокольчик/счётчик, одно открытие непрочитанных, повторное открытие действующих; опрос при запуске/каждые5минут, отложенный показ при других модальных окнах/скрытой вкладке. Escape/«Закрыть» сохраняет прочтение. Длинный текст прокручивается отдельно, закрытие остаётся видно. Desktop/VSCode зеркала синхронизированы; JetBrains содержит тот же runtime.
