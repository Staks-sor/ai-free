## Доставка и инструменты

Ошибка «не начал формировать ответ за45 секунд» возникала при уже сохранённом ответе: наблюдатель пропускал генерацию, а буквальное сравнение prompt ломалось после сериализации редактором сайта.

`providers/chatgpt/browser-proxy.mjs` захватывает user message ID нативного POST `/backend-api/f/conversation` или `/backend-api/conversation`. Recovery ищет завершённый ответ именно этого хода, проверяя ветку/статус; без ID остаётся строгое сравнение текста и времени. Подписка снимается в finally, повторная отправка не добавлена.

`agent-adapter.mjs` поясняет внешний JSON executor SYNVOX на каждом ходе: модель возвращает JSON, приложение выполняет разрешённый инструмент локально. `code-agent/run.mjs`, `loop-helpers.mjs` при явном отказе запускают один read-only list_files (depth1/100entries), возвращают результат модели; finish с отказом также отклоняется. Bootstrap ограничен JSON-протоколом без browser mode и прежних logs; permissions/license/checkpoint/cancellation сохраняются. Повторные отказы ограничены retry budget.

## Модели

Фиксированные GPT5.5/5.6 в каталоге были именами локальных селекторов Web, а не подтверждёнными версиями модели сайта. Теперь Web показывает режимы, сохраняет старые IDs как алиасы; текущую модель выбирает сайт. GPT6.1 Sol/Astra/Sol/Luna доступны отдельным подключением Codex, в пределах доступа аккаунта. Источники и остальные AI: `MODELS.md`.

`model-selection.mjs` и proxy используют точное нормализованное сравнение: High не совпадает с Extra High, Pro с Pro Extended. Неизвестная модель/неподтверждённый выбор дают `CHATGPT_MODEL_UNAVAILABLE`, delivery:not_sent до сообщения. Только явный useSessionModel разрешает оставить модель сайта; отсутствующий model у клиента разрешается в этот default.
