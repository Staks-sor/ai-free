# SYNVOX 0.5.60

2026-10-14. Альфа-версия; Desktop устанавливается вручную из ZIP. Плагины подготовлены для отдельной публикации владельцем.

## Изменения

- Новый рабочий интерфейс: проекты и чаты, вкладки «Чат / Задачи / Файлы», настоящая доска задач, план, проверки и управление продолжением. Обе темы, оригинальный значок и видимая подписка.
- Harness сохраняет состояние задачи, контролирует завершение плана и проверки изменений. Улучшены Stop, продолжение, восстановление сессий и работа нескольких аккаунтов.
- Доступ «Проект / Компьютер» выбирается для отдельного чата. Режим компьютера позволяет запускать установленные программы и работать вне проекта в рамках задачи пользователя.
- Картинки, `read_image`, снимки экрана и браузера передаются в общий Harness для ChatGPT, DeepSeek, Qwen, Google AI, GLM и Codex. Antigravity CLI остаётся текстовым.
- Исправлены URL-вложения Qwen, русское меню загрузки, подтверждение изображений и восстановление по file IDs. GLM получает завершённый ответ из штатного stream при зависшем интерфейсе.
- Исправлены сохранение состояния, гонки выбора чата и модели, остановка запросов, права на пути, проверка выполненных изменений и работа памяти.

## Платформы

Desktop, VS Code и PyCharm требуют Node.js 22+. Нативные модули содержат prebuilds для macOS Intel/Apple Silicon, Windows x64/ARM64 и Linux x64/ARM64.

Полное управление экраном требует системных разрешений и активного графического сеанса. В Linux нужен X11; Wayland и несколько мониторов пока не поддержаны. Windows использует `cmd.exe`, Unix — `sh`; агент получает эту информацию. Наличие модулей и проверки загрузки не подтверждают все сценарии ввода на каждой реальной ОС. Ручная Windows desktop acceptance ещё требуется.

Старую папку программы сохраните. Новую версию распакуйте отдельно, выполните `npm ci`, затем `npm start`. Чаты и авторизация находятся в пользовательском хранилище; его удалять не нужно. ZIP не включает подписанный автоматический updater.
