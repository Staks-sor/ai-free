# Объявления SYNVOX

Канал Desktop, VS Code и JetBrains получает публичный JSON:
`https://synvox.pro/api/v1/announcements.json`.
Исходник публикации: `website/static/api/v1/announcements.json`.
Первое обновление клиента с этим механизмом обязательно: выпущенная 0.5.64 объявления не поддерживает.

## Публикация следующего сообщения

1. Добавить объект в массив `announcements` существующего JSON. Не более20 объектов.
2. Присвоить новый уникальный `id` (латинские буквы, цифры, `.`, `_`, `-`, до100 символов). Для повторного показа исправленного сообщения нужен новый ID.
3. Указать `publishedAt` и `expiresAt` в UTC, формат `2026-11-17T12:00:00Z`. Будущие и истёкшие сообщения не показываются.
4. Заполнить `title` (до200 символов) и `body` (до8000) с `ru`/`en`. Достаточно одного языка; отсутствующий заменяется доступным. Текст отображается буквально: HTML и Markdown не исполняются.
5. Необязательный `link`: `label` с переводами (до80 символов), `url` только HTTPS на `synvox.pro` или `t.me`, без порта и учётных данных.
6. Проверить файл: `node scripts/validate-announcements.mjs`. Затем опубликовать JSON на сайте, сохранив точный адрес. Для снятия сообщения удалить объект или изменить срок.

Клиенты проверяют при запуске и каждые5минут; успешный ответ кешируется backend на5минут. Ошибка сети/некорректный JSON не блокирует работу, ранее загруженный feed остаётся в памяти до истечения сообщений. После перезапуска без сети feed не показывается до успешной загрузки. Безопасный предел ответа128КБ, таймаут5с, редиректы запрещены. Устанавливать для JSON `Cache-Control: no-cache` или эквивалентную ревалидацию CDN; иначе фактический срок доставки зависит от серверного кеша.

Новое сообщение открывается один раз, когда нет другого модального окна. Показ откладывается, пока вкладка скрыта; проверка возможности показа каждые15с. Кнопка с колокольчиком показывает число непрочитанных и позволяет открыть действующие объявления повторно. Закрытие/ Escape сохраняет прочтение только после успешной локальной записи.

Прочтение хранится по ID в `~/.deepseek-cli/announcements-read.jsonl`; перенос проекта, порт и перезапуск не сбрасывают его. Общий каталог данных означает общее прочтение между интерфейсами, использующими этот каталог. Файл содержит только ID объявлений, без ключей/чатов/лицензий. Никаких подтверждений или сведений об установке на сайт не отправляется; метрики охвата/доставки отсутствуют. Объявления и закрытие доступны при истёкшей подписке. Ссылка открывается через существующий безопасный механизм системного браузера. Выполняемый код, команды и автоматическое обновление через канал невозможны.
