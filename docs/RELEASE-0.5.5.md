# SYNVOX 0.5.5 — мини-отчёт

2026-10-05, Codex. Источники: текущий код, development context и чаты проекта «КВЕН», «ГУГЛ АИ», «ChatGPT». Старые диагностические сообщения сверены с текущими исходниками; полный live-прогон пяти AI не заявляется.

## Что вошло

- **Общий чат и кодинг.** В Coder каждое сообщение получает агент; модель выбирает обычный ответ, уточнение или инструменты. Роль, skill и сохранённые результаты проекта доступны обоим режимам. Простое сообщение не требует чтения файлов или запуска тестов.
- **Harness.** Сохранение цели, checkpoints, статуса, изменений и результатов проверок; ограниченное продолжение безопасных ошибок. Неизвестная доставка и прерванные tools не повторяются автоматически.
- **Агенты и задачи.** Сохранённые профили AI/роль/проект/skill, статусы, результаты проверок, Continue/Stop. Двойное продолжение не дублирует запрос, черновики сохраняются. Передача другому AI создаёт свежий чат с кратким контекстом.
- **Аккаунты.** До десяти для каждого Web AI, раздельные сессии, сохранённый основной аккаунт, rename/reconnect. Старые чаты сохраняют привязку.
- **Память и ресурсы.** Ограниченный контекст локального поиска, cache/workspace isolation, pacing/cooldown, очередь задач и ленивый пул браузеров с idle cleanup. Это не обещание низкой памяти при любой нагрузке.
- **Исправления.** Открытая или созданная папка сразу выбирается для чата. Подписи верхних кнопок уменьшены. Улучшены Qwen challenge/timeout diagnostics и постоянство browser fingerprint; универсального CAPTCHA solver нет.
